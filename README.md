## 🌌 PROJECT OVERVIEW

**Interactive 3D Particle Cube** is a desktop graphics project developed using Python, VisPy, and NumPy.

It demonstrates how numerical data can be transformed into interactive 3D particle visualizations.

Explore a particle-based cube, manipulate the camera, and experience interactive graphics rendering.

### ✦ Project Highlights

- ⚡ GPU-accelerated rendering using VisPy
- 🧊 Interactive 3D particle cube
- 🔄 Assemble and scatter particle animation
- 🎮 Mouse-driven 3D camera controls
- 📐 Efficient numerical operations with NumPy
- 💻 Python-based desktop visualization

## 🚀 QUICK START

### 01 — Clone the Repository

```bash
git clone https://github.com/Karthikeyan00045/first3dproject.git
```

### 02 — Open the Project

```bash
cd first3dproject
```

### 03 — Install Dependencies

```bash
python -m pip install numpy vispy PyQt6
```

### 04 — Launch the Animation

```bash
python main.py
```

A separate application window will open, displaying the interactive 3D visualization.

## 🎮 INTERACTIVE CONTROLS

| Input | Action |
|:---:|---|
| `SPACE` | Assemble / scatter the particle cube |
| `LEFT MOUSE + DRAG` | Rotate the 3D camera |
| `MOUSE SCROLL` | Zoom in and out |
| `CLOSE WINDOW` | Exit application |
